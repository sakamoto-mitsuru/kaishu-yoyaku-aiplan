# 業務管理機能 実画面モック（あいプラン様 確認用）

やわらぎ斎場の業務画面（葬家管理・回収予約・法事予約・配信管理）の実モックに、**業務管理機能**を追加した確認用の画面です。
データはすべてダミーで、外部のサーバーには接続しません。操作はブラウザ上だけで反映され、再読み込みで元に戻ります。

## 確認できること

| 画面 | 内容 |
| --- | --- |
| 回収予約 ＞ 業務一覧 | 日別・担当者別・業務別・状態で絞り込み。「業務を登録」「業務の種類を設定」 |
| 業務の登録・変更 | 業務の種類の設定に合わせて、葬家・エリア・金額の欄が切り替わる。担当者は複数名 |
| 業務の詳細 | 完了（結果メモ）、支払い状況（未／済）、キャンセル、お知らせメールの文面 |
| 業務の種類を設定 | 葬家 必須/任意/なし、エリア 必須/任意、金額 持つ/持たない、使う/使わない |
| 今日の予定 | 回収・訪問と並べて業務を表示。全員の予定では、エリアのない業務をタブの上にまとめて表示 |
| エリア別予約枠 | 業務を開始時刻の枠に表示。エリアのない業務は上部の「エリアなし」欄 |

## GitHub Pages での公開手順

1. このフォルダの中身を、リポジトリのルートにそのまま置いて push する（`index.html` がルートに来るように）
2. リポジトリの Settings ＞ Pages ＞ Build and deployment で「Deploy from a branch」を選び、Branch を `main`、フォルダを `/ (root)` にして保存
3. 数分後に `https://<アカウント名>.github.io/<リポジトリ名>/` で開ける

- 画面の切り替えは URL の `#/...` で行う方式のため、サーバー側の設定は不要です
- `.nojekyll` は GitHub Pages の変換処理を止めるためのファイルです。消さないでください

## 手元で開く場合

```
python3 -m http.server 4173
```

を実行して `http://localhost:4173/` を開く（`index.html` をダブルクリックしただけでは動きません）。

## 注意

- 公開リポジトリの GitHub Pages は、URL を知っている人なら誰でも見られます。画面のデータはダミーですが、画面のプログラム（ビルド済み）も含まれます
- 非公開リポジトリで GitHub Pages を使うには、GitHub の有料プラン（Pro / Team 以上）が必要です
